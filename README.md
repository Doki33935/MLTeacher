# Eduti — AI-репетитор для подготовки к ОГЭ и ЕГЭ

## 1. Постановка проблематики

### Целевой пользователь

**Артём, 15 лет, ученик 9 класса из Саратова.** Через 4 месяца сдаёт ОГЭ по математике и русскому языку. Семья не может позволить себе репетитора (средняя стоимость — 1500–3000 руб./час). Артём пытается готовиться самостоятельно: смотрит YouTube, решает варианты из открытого банка ФИПИ, но не понимает, почему ошибается в конкретных заданиях. Ему не хватает обратной связи — некому объяснить, где именно пробел и как его закрыть.

**Цели пользователя:**
- Получить балл, достаточный для поступления в профильный класс или колледж
- Понять свои слабые места и закрыть пробелы системно, а не хаотично
- Готовиться в удобное время, без привязки к расписанию репетитора

### Конкретная проблема

Ученик не знает, **что именно он не знает**. Он решает варианты целиком, тратит время на задания, которые уже освоил, и пропускает темы, в которых систематически ошибается. Без персонального анализа ошибок подготовка превращается в лотерею.

### Почему существующие решения не работают

| Решение | Ограничение |
|---------|-------------|
| **YouTube** | Пассивное потребление. Нет обратной связи, нет адаптации под конкретного ученика. Ученик смотрит объяснение, но не проверяет, понял ли он |
| **Банки заданий (ФИПИ, Решу ЕГЭ)** | Есть правильный ответ, но нет объяснения хода решения. Ученик видит «неправильно», но не понимает почему |
| **Репетиторы** | Эффективно, но дорого (60 000–150 000 руб. за курс подготовки). Недоступно для 60% семей за пределами Москвы и Санкт-Петербурга |
| **Готовые приложения** | Тесты без адаптивности. Одинаковый контент для всех. Не выявляют индивидуальные пробелы |

### Последствия нерешённой проблемы

- Низкий балл на экзамене — закрытые двери в профильные классы, вузы, колледжи
- Потеря мотивации из-за ощущения «я не понимаю и мне никто не поможет»
- Усиление образовательного неравенства: дети из обеспеченных семей получают репетиторов, остальные — остаются наедине с учебником

## 2. Анализ актуальности

### Масштаб проблемы

- **1.5 млн школьников** ежегодно сдают ОГЭ в 9 классе
- **700 000 выпускников** сдают ЕГЭ в 11 классе
- Итого: **более 2 млн учеников каждый год** нуждаются в качественной подготовке к экзаменам

### Неравенство доступа

- В Москве на одного репетитора приходится ~15 учеников. В регионах — более 150
- По данным НИУ ВШЭ, **62% семей** с доходом ниже медианного не могут позволить себе регулярные занятия с репетитором
- В сельской местности доступ к квалифицированным педагогам ограничен физически — ехать до ближайшего центра подготовки 1–2 часа

### Почему именно сейчас

- **Зрелость AI-технологий**: языковые модели (Claude, GPT) способны объяснять решения на уровне хорошего репетитора, адаптируясь под уровень ученика
- **Проникновение смартфонов**: 97% подростков 14–17 лет в России имеют смартфон — приложение доступно без дополнительного оборудования
- **Стоимость**: себестоимость одного AI-диалога — менее 1 рубля. Это в 3000 раз дешевле часа репетитора

### Риски старого сценария

Ученик, который продолжает готовиться хаотично:
- Тратит 80% времени на уже освоенные темы
- Не закрывает критические пробелы, которые стоят 5–10 баллов на экзамене
- Выгорает от ощущения бесполезности усилий

## 3. Предлагаемое решение — Eduti

### 3.1. Ключевые функции MVP

| # | Функция | Что делает | Какую проблему решает | Почему в MVP |
|---|---------|-----------|----------------------|--------------|
| 1 | **Диагностический тест** | AI задаёт серию вопросов по предмету, определяет уровень и пробелы | Ученик не знает, что он не знает | Без диагностики невозможна персонализация — это фундамент |
| 2 | **Пошаговый разбор ошибок** | При неправильном ответе AI объясняет ход решения, а не просто показывает ответ | Банки заданий дают только правильный ответ без объяснения | Главная ценность продукта — обратная связь |
| 3 | **Адаптивный диалог** | AI подстраивает сложность и стиль объяснения под уровень ученика | Репетитор адаптируется, YouTube и тесты — нет | Отличие от статичных решений |
| 4 | **История чатов** | Сохранение всех диалогов с возможностью вернуться к теме | Ученик забывает, что уже разбирал | Позволяет системно отслеживать прогресс |
| 5 | **Карта пробелов** | Визуализация тем, которые освоены и которые требуют работы | Нет понимания общей картины подготовки | Мотивирует и даёт направление |

**Подробнее о каждой функции:**

**1. Диагностический тест** — это не обычный тест с вариантами ответов. AI ведёт диалог, задаёт уточняющие вопросы, оценивает не только правильность, но и ход рассуждений. За 5–7 вопросов модель строит профиль ученика: какие темы освоены, где поверхностное понимание, а где полный пробел. Это экономит десятки часов, которые ученик потратил бы на решение заданий по уже освоенным темам.

**2. Пошаговый разбор ошибок** — ключевое отличие от всех существующих решений. Когда ученик ошибается, AI не говорит «неправильно, правильный ответ — 7». Вместо этого он показывает: «Ты ошибся на шаге 3, когда привёл дроби к общему знаменателю. Смотри: НОК(3,4) = 12, значит 1/3 = 4/12, а 1/4 = 3/12...». Это учит мыслить, а не запоминать ответы.

**3. Адаптивный диалог** — AI запоминает контекст разговора и уровень ученика. Если ученик быстро справляется — задания усложняются. Если не понимает объяснение — AI перефразирует проще, приводит аналогии из жизни, разбивает на более мелкие шаги. Это то, что делает хороший репетитор, но недоступно в статичных тестах.

**4. История чатов** — ученик может создавать отдельные чаты по предметам и темам («Математика — геометрия», «Русский — пунктуация»). Все диалоги сохраняются на сервере. Через неделю можно вернуться и повторить тему, которая вызывала трудности.

**5. Карта пробелов** — визуальное представление прогресса. Ученик видит: «Алгебра — 80% освоено, Геометрия — 45%, Теория вероятностей — 20%». Это даёт направление: понятно, куда вкладывать усилия, и мотивирует закрывать оставшиеся пробелы.

### 3.2. User Flow

```
Шаг 1: Открытие приложения
    → Экран приветствия с описанием возможностей

Шаг 2: Нажатие «Начать обучение»
    → Переход к списку чатов

Шаг 3: Создание нового чата
    → Модальное окно с вводом названия (например, «Математика ОГЭ»)
    → Создание диалога

Шаг 4: Диагностика
    → AI предлагает пройти короткий тест (5–7 вопросов)
    → Определяет уровень и слабые темы

Шаг 5: Работа над пробелами
    → AI предлагает задание по слабой теме
    → Ученик решает → AI разбирает ошибки пошагово
    → Цикл повторяется с усложнением

Шаг 6: Результат
    → Ученик видит прогресс, закрытые темы, рекомендации
```

**Пояснение к User Flow:**

- **Шаг 1–2:** Барьер входа минимален — никакой регистрации, никаких платных подписок. Ученик видит ценность продукта ещё до начала использования (три преимущества на экране приветствия).
- **Шаг 3:** Возможность именовать чаты позволяет организовать подготовку по предметам и темам. Если ученик не хочет думать над названием — по умолчанию создаётся «Новый чат», который автоматически переименуется по первому сообщению.
- **Шаг 4:** Диагностика — ключевой момент. За 5–7 вопросов AI определяет, какие темы ученик знает хорошо, а где есть пробелы. Это экономит часы бессмысленного решения заданий по уже освоенным темам.
- **Шаг 5:** Основной цикл обучения. AI не даёт готовый ответ — он ведёт ученика к пониманию через наводящие вопросы и пошаговые объяснения. Сложность адаптируется: если ученик справляется — задания усложняются, если нет — AI объясняет проще.
- **Шаг 6:** Ученик получает обратную связь о своём прогрессе. Это критически важно для мотивации — видеть, что усилия дают результат.

### 3.3. Технологический стек

| Слой | Технология | Обоснование |
|------|-----------|-------------|
| **Мобильное приложение** | React Native + Expo | Один код для Android и iOS. Быстрая итерация. Expo упрощает сборку и дистрибуцию |
| **Бэкенд** | Node.js + Express + TypeScript | Лёгкий, быстрый, идеален для API-сервера с небольшой бизнес-логикой |
| **База данных** | MySQL | Надёжное хранение истории диалогов, сессий, прогресса |
| **AI-движок** | Claude API (Anthropic) | Лучшее качество рассуждений на русском языке, безопасность, контролируемость |
| **Хостинг** | VPS (Linux) | Полный контроль, низкая стоимость (~500 руб/мес), возможность масштабирования |
| **Сборка** | EAS Build (Expo) | Облачная сборка APK/AAB без локальной настройки Android SDK |

**Почему этот стек:** минимальная сложность при максимальной скорости разработки. Один разработчик может создать и поддерживать MVP. TypeScript на обоих концах снижает количество ошибок. Expo убирает боль нативной сборки.

### 3.4. Ключевые экраны

#### Экран 1: Приветствие

**Когда видит:** при первом запуске приложения.

**Элементы:**
- Логотип Eduti (стилизованная буква «E» с академической шапочкой)
- Название и слоган: «Твой персональный AI-репетитор»
- Три ключевых преимущества (подготовка к ОГЭ/ЕГЭ, разбор по шагам, поиск пробелов)
- Кнопка «Начать обучение»

**Взаимодействие:** нажатие на кнопку → переход к списку чатов.

#### Экран 2: Список чатов

**Когда видит:** после приветствия и при каждом возврате из диалога.

**Элементы:**
- Заголовок «Мои чаты» с количеством диалогов
- Кнопка «+» для создания нового чата (с модальным окном ввода названия)
- Список карточек чатов (название, дата, кнопка удаления)
- Инструкция: «Пройди тест у нашей AI-модели, чтобы узнать какие пробелы в знаниях необходимо закрыть»

**Взаимодействие:** нажатие на карточку → открытие диалога. Нажатие «X» → подтверждение удаления. Нажатие «+» → модалка с именем нового чата.

#### Экран 3: Диалог с AI

**Когда видит:** после выбора или создания чата.

**Элементы:**
- Заголовок с названием чата и индикатором онлайн-статуса AI
- Область сообщений (пузыри: синие — ученик, тёмные — AI)
- Индикатор «AI думает...» при ожидании ответа
- Поле ввода с кнопкой отправки
- Сообщение об ошибке с возможностью повтора (нажатие)

**Взаимодействие:** ввод вопроса → отправка → получение пошагового объяснения от AI. При ошибке сети — нажатие на красное сообщение повторяет запрос.

## 4. Потенциал решения

### Что получает пользователь в первой версии

- **Персональный репетитор 24/7** — доступен в любое время, не устаёт, не осуждает за ошибки
- **Мгновенная обратная связь** — не нужно ждать проверки, объяснение приходит за секунды
- **Адаптивность** — AI подстраивается под уровень, не даёт слишком простых или слишком сложных заданий
- **Нулевая стоимость для ученика** — в отличие от репетитора за 2000 руб./час

### Развитие продукта (3–5 лет)

| Период | Функциональность |
|--------|-----------------|
| **6 мес** | Карта пробелов с визуализацией прогресса. Система достижений и мотивации |
| **1 год** | Поддержка всех предметов ОГЭ/ЕГЭ. Генерация персональных вариантов. Интеграция с расписанием подготовки |
| **2 года** | Голосовой режим (объяснения вслух). Групповые чаты для подготовки с одноклассниками. Аналитика для родителей |
| **3–5 лет** | Платформа для учителей (мониторинг класса). B2B для школ и образовательных центров. Выход на рынки СНГ |

### Расширение аудитории

- **Студенты** — подготовка к сессиям, разбор сложных тем
- **Учителя** — инструмент для создания индивидуальных заданий
- **Родители** — мониторинг прогресса ребёнка
- **Школы и образовательные центры** — B2B-лицензирование как дополнение к основной программе
- **Корпоративное обучение** — адаптация модели для профессиональной сертификации

### Главный технологический риск и митигация

**Риск:** зависимость от внешнего AI API (доступность, стоимость, качество ответов).

**Митигация:**
1. Архитектура с абстракцией AI-провайдера — возможность переключения между моделями (Claude, GPT, open-source) без изменения клиента
2. Кэширование типовых объяснений — снижение количества запросов к API на 40–60%
3. Retry-механизм с exponential backoff — устойчивость к временным сбоям
4. Мониторинг стоимости — алерты при превышении бюджета, автоматическое переключение на более дешёвую модель

## 5. Ожидаемый результат

### Для ученика (первая версия)

- **Понимание своих пробелов** — через 2 минуты после установки ученик знает, какие темы требуют внимания
- **Пошаговые объяснения** — не просто «неправильно», а разбор хода решения с указанием, где именно произошла ошибка
- **Персональный темп** — AI не торопит и не тормозит, подстраивается под скорость усвоения
- **Доступность 24/7** — можно готовиться в любое время, хоть в 11 вечера перед сном
- **Нулевая стоимость** — качество репетитора без финансового барьера

### Измеримые метрики успеха MVP

| Метрика | Целевое значение |
|---------|-----------------|
| Время до первого полезного результата | < 2 минут |
| Среднее количество сообщений за сессию | > 10 |
| Возврат пользователя на следующий день | > 40% |
| Оценка полезности ответа AI (по обратной связи) | > 4/5 |

### Как изменится опыт подготовки

**Было:** Ученик решает вариант целиком → видит 6 ошибок из 20 → не понимает почему → решает следующий вариант → те же ошибки → фрустрация → потеря мотивации.

**Стало:** Ученик проходит диагностику → AI выявляет 3 слабые темы → разбирает первую тему по шагам → ученик понимает принцип → решает аналогичное задание правильно → переходит к следующей теме → видит прогресс → мотивация растёт.

## Технические детали запуска

### Требования
- Node.js 18+
- MySQL 8+
- Expo CLI / EAS CLI

### Бэкенд
```bash
cd backend
cp .env.example .env  # заполнить AI_API_KEY, DB_HOST, DB_USER, DB_PASS
npm install
npm run dev
```

### Клиент (разработка)
```bash
cd client
npm install
npx expo start
```

### Сборка APK
```bash
cd client
eas build --platform android --profile preview
```
